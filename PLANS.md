# Планы Arcade

## USB Serial между Arduino и Raspberry

**Статус:** реализовано и развёрнуто на первой аркаде `192.168.3.156`. Вторая аркада ждёт обновления.

Arduino ESP32 считает время и обновляет табло MAX7219. Raspberry отправляет по `/dev/ttyUSB0` команды `ADD`, `PLAYPAUSE`, `STOP`, принимает состояния `READY`, `PLAYING`, `PAUSED`, `WAITING` и программно управляет контроллерами через EVIOCGRAB/uinput. GPIO реле для команд и обратной связи больше не используются.

### Проверка на первой аркаде

- [x] Прошить ESP32 по USB и проверить hash записи.
- [x] Подключить Pi к Serial на скорости 115200.
- [x] Проверить добавление 5 минут, `PLAYING` и разблокировку контроллеров.
- [x] Проверить `WAITING` и окончательный `STATE READY 0` после реальных 5 минут; контроллеры блокируются.
- [ ] Проверить переподключение USB и перезагрузку.

### Раскатка на вторую аркаду

`192.168.3.205` — **обязательно обновить после первой**. Там остаётся предыдущая конфигурация `Raspberry`.

1. Подключить её ESP32 к Raspberry по USB.
2. Прошить `1.2/Arcade_Timer_Arduino` с Serial-протоколом.
3. Залить текущий Arcade через `deploy.ps1`.
4. Проверить табло, оплату, навигацию, громкость, окончание времени и перезагрузку.

IP указаны текущие, перед заливкой перепроверить доступность и `machineId`. Пароли в план не записывать.
